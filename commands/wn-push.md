`$ARGUMENTS` 를 제목으로 현재 노드 아래로 내려갑니다. 전제는 하나입니다 — **이 가지가 지금 현재 노드를 막고 있어야 합니다.** 막고 있지 않으면 `/wn-park` 를 쓰세요.

내려가기 전에 현재 노드의 복귀지점을 반드시 적습니다. "어디까지 했고 다음에 뭘 하려 했는지" 한 문장. 대화 맥락에서 초안을 만들되, 추측이 섞이면 사용자에게 확인하세요. 45분 뒤에 이 문장 하나를 돌려받는 것이 이 도구의 존재 이유입니다.

```bash
python3 "${CLAUDE_PLUGIN_ROOT}/src/wn.py" push "<제목>" --resume-note "<복귀지점 한 문장>"
```

**종료 코드 3 (게이트) 이 나오면 stderr 에 나온 게이트 문구를 그대로 사용자에게 보여주고 거기서 멈추세요.** 절대 스스로 `--force` 를 붙여 재시도하지 마세요. 사용자가 명시적으로 "내려가자"라고 답할 때만 `--force` 를 붙입니다. 이 게이트를 대신 통과해 주는 순간 이 도구는 쓸모가 없어집니다.

게이트는 둘입니다. 깊이 게이트는 루트에서 세 칸 아래로 내려가려 할 때, WIP 게이트는 이미 열린 노드가 상한(`wip_limit`, 기본 3)에 닿았을 때 걸립니다. 둘 다 종료 코드 3 이고 상태는 한 글자도 바뀌지 않습니다. WIP 게이트가 걸렸다면 `--force` 를 제안하기 전에 `/wn-pop` 으로 끝난 것을 닫거나 `/wn-park` 로 담아두는 쪽을 먼저 제시하세요.
