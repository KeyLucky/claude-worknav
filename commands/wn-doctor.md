```bash
python3 "${CLAUDE_PLUGIN_ROOT}/src/wn.py" doctor
```

출력을 그대로 사용자에게 보여주세요. **요약하지 마세요** — 각 줄의 `→` 가 다음에 칠 명령입니다.

읽는 법입니다.

**훅 실행** — 훅 스크립트를 임시 프로젝트에서 실제로 구동해 종료코드·출력 모양·지연을 봅니다. 여기가 `✗` 면 코드가 깨진 것이고, `WORKNAV_HOOK_DEBUG=1` 로 다시 돌리면 예외가 보입니다.

**주입 기록** — 위와 다릅니다. 훅 실행은 "지금 돌리면 도는가"만 보고, 이건 **실제 세션에서 하네스가 불러 줬는가**를 봅니다. `주입 0턴` 이면 등록은 됐는데 한 번도 안 불린 것이고, 이게 가장 중요한 신호입니다.

**마켓플레이스** — 로컬 사본의 커밋과 날짜를 보여줍니다. 원격이 앞서 있는지는 네트워크 없이 알 수 없으므로 추측해서 "낡았다"고 말하지 않습니다. 대신 **설치본이 마켓플레이스 사본과 다름** 이 뜨면 확실한 문제입니다 — 이 상태에서 Uninstall → Install 을 하면 같은 옛날 커밋이 도로 들어오므로, Marketplaces 탭에서 Update 를 먼저 해야 합니다.

**표지판 일치** — 터미널(파이썬)과 상태바(JS) 두 렌더러가 같은 문자열을 내는지 대조합니다. 어긋나면 `.vsix` 가 소스보다 낡은 것입니다.

`·` 는 "해당 없음"이지 문제가 아닙니다. 상태 파일이 없는 프로젝트에서는 대부분 `·` 로 나오는 게 정상입니다.

이 명령은 **사용자의 작업 상태를 바꾸지 않습니다.** 훅을 구동할 때도 임시 프로젝트를 쓰므로 보류함에 아무것도 담기지 않습니다. 진단 결과가 나쁘게 나와도 종료코드는 0 입니다.
