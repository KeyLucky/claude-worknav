description: worknav — 이번 작업의 루트 목표를 한 줄로 확정한다
---

`$ARGUMENTS` 를 이번 작업의 루트 목표로 설정하세요. 비어 있으면 사용자에게 한 줄로 물어보고 받으세요.

목표 한 줄이 없으면 나중에 "샜다"를 판정할 기준 자체가 없습니다. 추측해서 채우지 말고 사용자 표현을 그대로 쓰세요.

```bash
python3 "${CLAUDE_PLUGIN_ROOT}/src/wn.py" root "<목표 한 줄>"
```

종료 코드 2 (열린 루트가 이미 있음) 가 나오면 **자동으로 `--force` 를 붙이지 마세요.** 기존 루트를 알려주고 이어서 할지 새로 시작할지 물어보세요. `--force` 는 기존 트리를 보관(archive)하고 새로 시작합니다.
