`$ARGUMENTS` 를 보류함에 담습니다. **커서는 움직이지 않습니다.** 이게 PARK 의 전부입니다.

새로 생긴 의문·부가작업의 기본 처리는 언제나 park 입니다. 확인 질문 없이 담고 한 줄만 보고하세요. 여기서 되물으면 작업 흐름이 끊깁니다.

```bash
python3 "${CLAUDE_PLUGIN_ROOT}/src/wn.py" park "<제목>"
```

제목은 나중에 혼자 읽어도 뭔지 알 수 있게 씁니다. "그 에러" 말고 "numpy 버전 불일치 경고".
